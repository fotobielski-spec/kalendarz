# Kalendarium+

Nowoczesna aplikacja kalendarza wydarzeń z polską lokalizacją.

## Funkcje

- Widok miesięczny z nawigacją między miesiącami
- Dodawanie, edycja i usuwanie wydarzeń
- Kategorie wydarzeń: Praca, Osobiste, Święto, Inne
- Panel boczny z listą wydarzeń wybranego dnia
- Tryb jasny i ciemny
- Automatyczny zapis w localStorage
- Responsywny interfejs

## Uruchomienie

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:5173`.

## Budowanie

```bash
npm run build
npm run preview
```

## Technologie

- React 19
- TypeScript
- Vite
