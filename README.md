# Kalendarz

Repozytorium projektu aplikacji kalendarza.

## Status projektu

Na tym etapie repozytorium zawiera tylko podstawowy plik dokumentacji. Kod aplikacji, konfiguracja środowiska oraz instrukcje uruchamiania nie zostały jeszcze dodane.

## Zakres dokumentacji

Ten dokument powinien zostać uzupełniony, gdy w repozytorium pojawi się implementacja aplikacji. W szczególności warto wtedy dodać:

- opis głównych funkcji aplikacji,
- wymagania systemowe i zależności,
- instrukcję instalacji,
- instrukcję uruchomienia lokalnego środowiska,
- opis sposobu uruchamiania testów,
- informacje o strukturze katalogów.

## Uwagi dla kontrybutorów

Przed dodaniem instrukcji instalacji lub uruchomienia należy upewnić się, że odpowiadają one faktycznej konfiguracji projektu. Dokumentacja powinna być aktualizowana razem ze zmianami w kodzie aplikacji.
